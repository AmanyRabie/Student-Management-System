# Student Management System

## Description

A simple Student Management System built with Python using Object-Oriented Programming (OOP).

This project allows users to manage student records through a command-line interface while saving data automatically using JSON.

---

## Features

* Add Student
* Remove Student
* Find Student by ID
* Update Student GPA
* Display All Students
* Automatic Save to JSON
* Automatic Load from JSON
* Error Handling using Exceptions

---

## Technologies Used

* Python 3
* Object-Oriented Programming (OOP)
* JSON
* File Handling
