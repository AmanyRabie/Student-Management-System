# Student Management System

A Python-based Student Management System that allows users to manage student information through a command-line interface.

## Version 2.0

Version 2 adds several features for searching, sorting, statistics, and exporting student data.

### Features

* Add Student
* Remove Student
* Find Student by ID
* Update Student GPA
* Display All Students
* Search Students by Name
* Search Students by Department
* Sort Students by GPA
* Calculate Student Statistics
* Find Highest GPA Student
* Find Lowest GPA Student
* Calculate Average GPA
* Save Student Data to JSON
* Load Student Data from JSON
* Export Student Data to CSV
